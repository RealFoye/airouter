## 今日收获 / 教训

1. **Tier 编号方向**：Tier 1 = 贵，Tier 3 = 便宜。`max(tiers)` 是最便宜的，不是最贵的。
2. **嵌套配置访问**：Pydantic 嵌套模型必须用完整路径（`m.cache.supports_prompt_caching`），`getattr` 只查顶层属性。
3. **Rich 不适合机器输出**：`console.print()` 会自动折行，JSON 输出必须用 `print()`。
4. **时间偏移必须有界**：`base + timedelta(minutes=random)` 可能进入未来，必须先算 `remaining` 再 clamp。
5. **测试不能依赖本地文件**：用 `tmp_path_factory` + fixture 生成临时数据，CI/干净 checkout 都能跑。
6. **单一数据源**：所有模型配置（定价、tier、缓存支持）都从 `models.yaml` 派生，杜绝硬编码漂移。
